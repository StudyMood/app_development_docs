## 🚀 What's New in Version 1.2.0

### ✨ New Features
- **Live Interactive Map Tracking:** Ab aap apne delivery rider ko real-time map par dekhein with dynamic traffic-based ETA.
- **1-Click UPI Payment:** Google Pay, PhonePe, aur Paytm ke sath direct seamless intent payment integration.
- **Pure Veg Mode Filter:** Ek tap me saare non-veg items filter karein aur verified pure veg restaurants browse karein.

### ⚡ Performance Improvements
- **Faster App Launch:** Cold start boot time ko **40% reduce** kiya gaya hai (from 2.8s to 1.7s).
- **Reduced Data Usage:** High-resolution food images ab modern WebP format me load hoti hain, jisse mobile data 35% kam consume hota hai.

### 🐛 Bug Fixes & Stability
- Fixed an issue where the checkout button was occasionally covered by the on-screen keyboard on smaller Android screens.
- Resolved GPS location permission prompt freeze on iOS 17 devices.
- Fixed coupon code discount calculation edge case during midnight order transactions.
